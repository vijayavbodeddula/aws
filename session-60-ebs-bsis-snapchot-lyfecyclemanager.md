Error	                    Meaning
Connection timed out	    Traffic is being dropped before it reaches the application 
                            (often   Security Group, NACL, or firewall).

Connection refused	        The connection reached the server, but nothing is listening on                          that port (or the service actively rejected it).

AWS Snapshot
    An AWS Snapshot is a backup of an Amazon EBS (Elastic Block Store) volume.
    It allows you to restore data or create new EBS volumes from the saved state.
